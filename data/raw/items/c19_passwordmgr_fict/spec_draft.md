Cryptavo is a password manager that keeps its vault as a single encrypted file on the user's own storage. Rather than running a hosted sync service, it leaves synchronisation to whatever file service the user already has, so the user configures and maintains that sync themselves. Unlocking requires both a master password and a hardware security key that must be present; losing both the key and the password locks the vault permanently, since no company server holds a copy. Authenticator codes are generated inside the vault alongside stored credentials. The free tier holds unlimited entries on a single device; the paid tier adds vault sharing across devices and audit reports. Desktop clients exist for Windows, macOS, and Linux, and mobile clients for iOS and Android. There are no browser extensions, so nothing fills credentials into a web page automatically, and no web vault, so a machine without a client cannot open the file. A command line interface is available for scripted use. Vaults export either as an encrypted archive or as a plain CSV file, which carries no encryption, for migration to another manager. The vault file can be backed up like any other document, and moving it between machines needs nothing beyond the file itself.
