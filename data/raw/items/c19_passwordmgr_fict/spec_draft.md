Cryptavo is a password manager that keeps its vault as a single encrypted file on the user's own storage. Rather than running a hosted sync service, it leaves synchronisation to whatever file service the user already has, so the user configures and maintains that sync themselves; when the same vault is changed on two devices before syncing, the file service writes a conflicting copy that is resolved by hand. Unlocking requires both a master password and a hardware security key, which must be present at every unlock. No online account and no email registration are needed, so nothing about the vault is held on a company server; losing both the key and the password locks the vault permanently. Authenticator codes are generated inside the vault alongside stored credentials, and a password generator produces entries with configurable length and character rules. The free tier holds unlimited entries on a single device; the paid tier adds vault sharing across devices and audit reports. Desktop clients exist for Windows, macOS, and Linux, and mobile clients for iOS and Android. There are no browser extensions, so nothing fills credentials into a web page automatically, and there is no web vault, so a machine without a client cannot open the file. A command line interface is available for scripted use. The vault file is backed up like any other document and moved between machines as a file. Vaults export either as an encrypted archive or as a plain CSV file, which carries no encryption of its own. Entries hold a title, a username, a password, a site address, and free-text notes, and search runs across those fields within the open vault. Maintenance involves keeping a copy of the vault file and the hardware key in separate places, since neither can be reissued by the maker.
