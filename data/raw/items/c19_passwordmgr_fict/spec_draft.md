Cryptavo is a password manager that keeps its vault as a single encrypted file on the user's own storage. Rather than running a hosted sync service, it leaves synchronisation to whatever file service the user already has, so the vault file moves between machines the same way other documents do. Unlocking requires both a master password and a hardware security key. Authenticator codes are generated inside the vault alongside stored credentials. The free tier holds unlimited entries on a single device; the paid tier adds vault sharing across devices and audit reports. Desktop clients exist for Windows, macOS, and Linux, and mobile clients for iOS and Android; there are no browser extensions and no web vault. A command line interface is available for scripted use. Vaults export either as an encrypted archive or as a plain CSV file for migration to another manager.
