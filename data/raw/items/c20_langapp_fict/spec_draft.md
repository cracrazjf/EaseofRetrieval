Quenlo is a language-learning application built on spaced repetition, in which each vocabulary item and phrase returns for review on a schedule derived from how reliably the learner has recalled it before; missed days accumulate a larger review queue. Twelve languages are offered, each with a graded reading track and a matching listening track, a catalogue narrower than the large course libraries. Lessons combine graded texts, audio clips, and typed recall prompts, so answers are typed rather than tapped, and there is no speech recognition for pronunciation practice. Lesson packs download in advance for study without a connection. A review queue shows what is due, and per-item retention statistics record how each entry is performing over time. The application runs on iOS, Android, and in a web browser; on a desktop it is browser only, with no installed client. New accounts receive a fourteen-day trial, after which a subscription is required and no ongoing free tier remains. Vocabulary lists export as CSV files, and the review schedule carries over when a learner returns after a break. Each item's schedule is stored with the account, so a learner moving between the phone and the browser resumes the same queue.
