Quenlo is a language-learning application built on spaced repetition: each vocabulary item and phrase returns for review on a schedule derived from how reliably the learner recalled it before. Twelve languages are offered, a catalogue narrower than the large course libraries, and each language pairs a graded reading track with a matching listening track. Lessons combine graded texts, audio clips, and typed recall prompts, and every item carries audio recorded by a native speaker. Answers are typed rather than tapped, and there is no speech recognition, so pronunciation is not practised or scored. There are no grammar lessons; the courses cover vocabulary, reading, and listening only. Lesson packs download in advance for study without a connection. A review queue shows what is due, and per-item retention statistics record how each entry is performing over time. Learners add their own items to the review queue alongside the supplied ones, and existing vocabulary lists import as CSV. Daily reminders fire when items come due. The schedule is stored with the account, so a learner moving between the phone and the browser resumes the same queue. Missed days accumulate a larger review queue, which returns in full at the next session. The application runs on iOS, Android, and in a web browser; on a desktop it is browser only, with no installed client. There are no forums, classes, or shared decks, so learners work without contact with other learners. New accounts receive a fourteen-day trial, after which a subscription is required and no ongoing free tier remains. Vocabulary lists export as CSV files, and the review schedule carries over when a learner returns after a break. Each item stores its own recall record, the date it is next due, and the track it came from, so the queue rebuilds itself after every session without any manual scheduling.
