Quenlo is a language-learning application built on spaced repetition, in which each vocabulary item and phrase returns for review on a schedule derived from how reliably the learner has recalled it before. Twelve languages are offered, each with a graded reading track and a matching listening track. Lessons combine graded texts, audio clips, and typed recall prompts rather than multiple-choice tapping. Lesson packs download in advance for study without a connection. A review queue shows what is due, and per-item retention statistics record how each entry is performing over time. The application runs on iOS, Android, and in a web browser; there is no installed desktop client. New accounts receive a fourteen-day trial, after which a subscription is required to continue. Vocabulary lists export as CSV files for use in other tools, and the review schedule carries over when a learner returns after a break.
