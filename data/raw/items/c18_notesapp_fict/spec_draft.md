Trelbin is a note-taking application built around outline documents whose sections collapse and expand and can be linked to one another. There are no table or database views, so structured records are kept as lists inside a document. Documents are stored locally on the device by default, as plain files that other applications can open, and an optional sync service, configured separately, copies them between installations with end-to-end encryption. Because storage is local, full editing and document creation work offline without any connection. A free tier holds unlimited local documents, syncs across two devices only, and caps attachments at 20 megabytes. The paid tier lifts the device limit and adds version history, which is available on the paid tier alone, along with full-text search inside attachments. Search across the local library runs on both tiers. Files of any type attach to individual outline sections. Documents export as Markdown, plain text, or PDF. Clients exist for macOS and Windows on the desktop and for iOS and Android on mobile; there is no Linux client, and there is no browser client, so a machine without an install cannot open documents. Documents cannot be shared with people outside the account, and there are no guest links of any kind, so a document reaches another person only by exporting it to a file first. When the same document is edited offline on two devices, the sync service writes a conflicting copy that is merged by hand. Two tiers are offered, free and paid, with no per-seat team plan. Section headings carry their own links, so one document can point at a specific place inside another rather than at the whole file. Maintenance of a library involves keeping the document folder backed up, since the copy on the device is the original.
