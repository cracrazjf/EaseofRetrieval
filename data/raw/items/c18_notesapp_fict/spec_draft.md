Trelbin is a note-taking application built around outline documents whose sections collapse and expand and can be linked to one another. There are no table or database views for structured records. Documents are stored locally on the device by default, and an optional encrypted sync service, switched on and configured separately, copies them between installations. Because storage is local, full editing and document creation work offline without any connection. A free tier covers unlimited local documents, syncing across two devices only, and attachments capped at 20 megabytes. The paid tier removes the device limit and adds version history, available on that tier only, and full-text search across attachment contents. Search across the local library is available on both tiers. Documents export as Markdown, plain text, or PDF files. Clients exist for macOS and Windows on the desktop and for iOS and Android on mobile; there is no browser client, so a machine without an install cannot open documents, and individual documents cannot be shared with people outside the account holder's own installations. There are no guest links for collaborators of any kind, so a document reaches other people only by exporting it to a file first.
