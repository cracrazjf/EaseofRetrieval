Bitwarden is a password manager with clients across every mainstream platform. The free tier stores unlimited passwords and syncs across unlimited devices, and independent reviews describe the free tier as covering the core function fully. Free accounts share items with one other user and no more. Integrated authenticator codes, file attachments, emergency access, and security reports each sit behind the paid individual tier. A families plan covers six paid accounts and adds unlimited shared collections. Desktop clients exist for Windows, macOS, and Linux; mobile clients for iOS and Android; and browser extensions for nine browsers including Chrome, Firefox, Safari, and Edge. A web vault opens from any browser, and a command line interface is available for scripted use. The server can be self-hosted, so an organisation keeps the vault data on its own hardware. Vault data exports as JSON or CSV, and imports arrive from other managers in their own formats. Two-step login is available on every tier through email codes and authenticator apps. Vault contents are encrypted on the device before they reach the sync service, and the master password is never transmitted; there is no master password recovery, so an account whose password is lost cannot be reopened. The source code is published and has been reviewed in independent audits. Independent reviews describe the interface as less polished than competing managers and report autofill as inconsistent on complex sites. Support for free-tier users is limited to community forums rather than direct channels. Shared collections let a family plan hold credentials several members reach, while personal items stay in each member's own vault, and every client reads the same vault after it syncs. Entries hold logins, cards, identities, and free-text notes, and a generator produces new passwords to a set length and character mix.
