Bitwarden is a password manager with clients across every mainstream platform. The free tier stores unlimited passwords, syncs across unlimited devices, allows sharing with one other user, and covers the core function fully. Integrated authenticator codes, file attachments, emergency access, and security reports sit behind the paid individual tier. A families plan covers six paid accounts and adds unlimited sharing collections. Desktop clients exist for Windows, macOS, and Linux; mobile clients for iOS and Android; and browser extensions for nine browsers including Chrome, Firefox, Safari, and Edge. A web vault opens from any browser and a command line interface is available for scripted use. The source code is published and has been reviewed in independent audits. Vault contents are encrypted on the device before they reach the sync service, and the master password is never transmitted, so recovery depends on the user retaining it. Independent reviews describe the interface as less polished than competing managers and autofill as inconsistent on complex sites. Support for free-tier users is limited to community forums rather than direct channels. Shared collections let a family plan hold credentials that several members reach, while personal items stay in each member's own vault.
