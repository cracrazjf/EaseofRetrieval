Bitwarden is a password manager with clients across desktop, mobile, and browser platforms. The free tier stores unlimited passwords, syncs across unlimited devices, and allows sharing with one other user. Integrated authenticator codes, file attachments, emergency access, and security reports sit behind the paid individual tier. A families plan covers six paid accounts and adds unlimited sharing collections. Desktop clients exist for Windows, macOS, and Linux; mobile clients for iOS and Android; and browser extensions for nine browsers including Chrome, Firefox, Safari, and Edge. A web vault opens from any browser, and a command line interface is available for scripted use. The source code is published and has been reviewed in independent audits. Vault contents are encrypted on the device before they reach the sync service, and the master password is never transmitted.
