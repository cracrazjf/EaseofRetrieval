Stillbrook is a focus timer for desktop work. During a session an illustrated scene gradually fills in with detail, and the detail already earned remains when the session is paused or ended early. While a session runs, the application blocks a user-selected list of desktop applications and websites. An ambient sound library plays alongside the timer. Session history is recorded and summarised by day and week. The free tier covers the timer, the blocking list, three ambient tracks, and seven days of history. The paid tier adds the full sound library, unlimited history, and additional scene variants. Clients run on macOS and Windows, with a companion web dashboard for reviewing statistics; there is no mobile client, so phone use during a session is not restricted. Session data exports as CSV from the dashboard, and the blocking list can be edited between sessions but not while one is running.
