Stillbrook is a focus timer for desktop work. During a session an illustrated scene fills in with detail, and the detail already earned is kept when a session is paused or abandoned early, so nothing is lost by abandoning a session halfway. Session length is set anywhere from five to 180 minutes in one-minute steps. While a session runs, the application blocks a user-selected list of desktop applications and websites; the blocking list is edited between sessions and cannot change while a session runs. There is no mobile client, so phone use during a session is unrestricted, and no client exists for tablets either. No schedule starts a session automatically, and every session is started by hand. There are no shared or group sessions of any kind, so sessions cannot be shared with anyone else. An ambient sound library plays alongside the timer. Session history is recorded and summarised by day and by week, showing total focused time, session counts, and which applications were blocked most often. Clients run on macOS and Windows, and a companion web dashboard reviews those statistics from any browser. Session data exports from the dashboard as CSV. Sessions run offline and sync once the machine reconnects; an account is optional, and the timer runs on one machine without an account. The free tier covers the timer, the blocking list, three ambient tracks, and seven days of history. The paid tier adds the full sound library, lifts the history limit entirely, and unlocks additional scene variants. Finished sessions fund nothing outside the application: there is no tree planting, donation, or other real-world component. Maintenance of the blocking list and the scene library happens from the same settings panel, and each completed session is added to the running day and week totals shown on the dashboard.
